# Security Policy

## Supported versions

The active supported release line is `v1.x`.

## Reporting a vulnerability

Please report security issues privately instead of opening a public GitHub issue.

Include:

- affected version or commit
- vulnerable class/function
- reproduction steps
- expected and actual result
- impact assessment
- any safe proof-of-concept payloads

The maintainer will review the report and prepare a fix or mitigation guidance before public disclosure.

## Scope

This library provides reusable security building blocks. It does not automatically make an application secure unless the application integrates the controls correctly, configures production settings safely, and tests the final deployment.
